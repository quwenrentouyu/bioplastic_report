## 1. 序论
塑料加工容易、重量轻、生产成本低，因此在包装材料、电子产品、汽车零部件、医疗材料、建筑材料等几乎所有产业中都被广泛使用。经济合作与发展组织（OECD）指出，2019年全球塑料产量约为4.6亿吨，约为2000年的两倍。同一年产生的塑料废弃物约为3.53亿吨，其中仅9%得到回收利用。

塑料问题并不只是废弃物污染。塑料在2019年约占全球温室气体排放量的3.4%。这是因为目前使用的大多数塑料都以石油或天然气为原料的原生塑料。随着废弃物污染和气候变化同时加剧，寻找替代石油材料的需求也越来越大。

作为替代方案，生物塑料受到关注。然而，“生物”这一名称并不等于一定对环境有利。欧盟（EU）委员会说明，来自植物的生物基塑料并不一定会生物降解或进行堆肥处理。因此，本报告将从材料分类角度分析其环境效应。

本报告的目的在于说明生物塑料在减少环境负担方面的原理与局限，并通过与传统塑料的比较，提出其环境效应和产业扩散效应。第二章将讨论生物塑料的概念、碳循环、生物降解条件，并以表格比较关键指标。第三章将分析欧盟的法规、市场规模和应用领域。第四章将总结内容并展望未来。

## 2. 生物塑料的环保原理与环境效应

### 2.1 生物塑料的概念与分类
生物塑料通常按两项标准进行分类：其一是可以被微生物作用分解的可生物降解塑料；其二是以植物等生物资源为原料的生物基塑料。这两个标准相互独立，因此“生物基塑料”并不等于“可生物降解”。

可生物降解塑料包括聚乳酸（polylactic acid, PLA）和聚丁二酸丁二醇酯（PBAT）等。PLA是以玉米等植物中的糖发酵后得到的乳酸为原料。PBAT则在很多情况下仍以石油基原料生产，因此“可生物降解”并不意味着“都属于生物基”。

生物基塑料的代表例子是生物PET（Bio-PET）。它的原料来自植物，但其化学结构与普通PET相同，因此并不具备生物降解性质。另一方面，可堆肥塑料属于可生物降解塑料的一个子类别，通常需要在工业堆肥设施中分解，并且必须先进行收集后再处理。

### 2.2 原料与碳循环及温室气体减排潜力
传统塑料以石油或天然气为原料。根据 OECD 报告援引的相关新闻，塑料温室气体排放中约90%来自化石燃料的生产和转化过程。相比之下，生物塑料的原料如玉米和甘蔗在生长过程中会吸收大气中的二氧化碳，因此有人主张：废弃时释放的碳可以被此前吸收的碳所抵消，这称为碳中和（carbon neutrality）。

然而，从整个生产链来看，还需要考虑作物种植、施肥、运输和加工等阶段所产生的排放。因此，不能简单地将生物塑料直接视为碳中和材料。这些影响通常通过生命周期评价（Life Cycle Assessment, LCA）来量化。Walker 和 Rothman 对25篇 LCA 研究进行了分析，比较了化石基材料39个案例和生物基材料50个案例。研究结果显示，任何聚合物都不能被简单地认定为在所有影响类别中环境影响最低。同一类聚合物的不同研究之间也存在较大差异，其主要原因在于废弃处理方式和吸收二氧化碳的认可方式等方法差异。

也有个别案例。PLA 制造商 NatureWorks 的研究团队在2014年分析了其 PLA 生产过程的生命周期清单，并报告称 PLA 生产的温室气体排放低于 PET、聚苯乙烯和 ABS 树脂。然而，这一数据仅适用于该工厂使用玉米原料的特定生产流程，并不代表所有 PLA。再者，此研究由制造商所属研究人员撰写，因此需要谨慎看待。因此，不能将某个减排率普遍推广到所有生物塑料上。

从[表1]可以看出三个关键点。第一，从原料角度来看，生物塑料可以降低对化石燃料的依赖。第二，生物降解是条件性的，名称中带有“生物”并不意味着所有材料都能降解。第三，温室气体减排效果受材料与评价方法影响较大，因此不能一概而论，必须逐一核实。

### 2.4 生物降解机制与废弃阶段的环境影响
生物降解是指微生物和酶将高分子链切断，最终分解为水和二氧化碳的过程。然而这一过程受到温度、湿度等环境条件影响很大。联合国环境规划署（UNEP）指出，完全生物降解在海洋环境中很难在常规条件下实现，部分聚合物甚至需要在工业堆肥设施和50℃以上的环境中长期处理。同一报告也确认：PE、PP、PVC 等广泛使用的塑料在海洋环境中不会自然生物降解。

因此，废弃物管理体系必须同步完善。欧盟委员会解释说，可堆肥塑料必须先在工业堆肥设施中进行分解，并且必须先被收集起来。现实中，全球塑料废弃物的回收率仅为9%，光靠替换材料并不能解决问题。OECD 也指出，除了发展再生塑料市场，还需要配套抑制整体消费的政策。

同时，安全性也必须保持谨慎。与石油基塑料一样，生物塑料中也可能发生化学物质迁移。因此，食品接触产品的安全性不能仅由材料类别来决定，而需要针对具体产品进行测试。

## 3. 生物塑料的产业扩散效应与未来发展可能性

### 3.1 欧盟环境规制与市场应对
欧盟于2019年通过《一次性塑料指令》（Directive (EU) 2019/904），禁止在市场上销售具有替代品的一次性产品。禁令对象包括餐具、盘子、吸管、棉签棒、饮料搅拌棒、发泡聚苯乙烯食品容器以及氧化生物降解塑料制品。这项禁令自2021年7月3日起在所有成员国生效。该指令还要求塑料饮料瓶的回收含量在2025年前达到25%，到2030年达到30%以上。

财政压力同样存在。欧盟自2021年1月起，对未回收的塑料包装废弃物按每公斤0.80欧元向成员国征收分摊金。这并不是直接向企业征税，而是成员国向欧盟预算缴纳的分摊金。不过，成员国仍可能在国内政策中将这一负担转嫁给企业。

碳边境调节机制（Carbon Border Adjustment Mechanism, CBAM）依据规则（EU）2023/956制定，适用对象包括钢铁、水泥、铝、肥料、电力和氢。塑料目前尚未纳入范围。但该规则规定，在过渡期结束前，可对有机化学品等其他产品是否扩大范围进行审查。因此，CBAM 不能直接作为生物塑料推广的充分依据，仍需观察其是否扩大覆盖范围。

综上，欧盟的规制优先考虑减量和回收扩展，而非单纯依赖材料替代。欧盟委员会于2022年11月通过的政策框架也指出，生物基、可生物降解、可堆肥塑料只有在能够改善整体环境影响的前提下才有意义。这一框架不具有法律约束力，同时欧盟也尚未出台统一规范这些材料的法律。

### 3.2 市场规模与应用领域
欧洲生物塑料协会（European Bioplastics）与 nova-Institute 联合发布的资料显示，全球生物塑料生产能力预计将从2024年的约247万吨增长到2029年的约573万吨，约增长2.3倍。然而，2024年的实际产量仅为144万吨，产能利用率为58%，生物塑料仅占全球塑料总产量约0.5%。该协会认为，生产能力与实际产量之间的差距是否缩小，取决于包装和包装废弃物法规（PPWR）等规制的解释方式。

按应用领域来看，2024年包装行业占比最大，约45%，约112万吨。除此之外，还广泛用于纺织、消费品、汽车和农业产品。医疗领域中，PLA 是研究最广泛的可生物降��脂肪族聚酯，已被应用于伤口护理、支架和药物传递等领域。

若要拓展到高附加值领域，需要突破材料性能的限制。Farah 等人总结指出，PLA 的稳定性、加工性和降解特性决定了其应用适配性，而共混和核剂添加等改性方法正在被研究中。这些技术难题解决的速度，将决定以包装为中心的市场是否能够扩展到其他产业。

## 4. 结论
本报告比较了生物塑料与传统塑料的环境效应和产业扩散效应。第一，生物塑料可以利用植物原料，降低对化石燃料的依赖，但其温室气体减排效果会因材料和评价方法不同而差异很大，因此不能用单一数值概括。第二，生物降解通常发生在工业堆肥设施等特定条件下，而生物基塑料未必能够生物降解。第三，市场虽然在增长，但目前仅占整个塑料市场约0.5%，且欧盟的规制也更倾向于减量和回收，而不是单纯替代材料。

未来，生物塑料的效果将更多取决于收集体系、堆肥基础设施、明确的标识体系和材料性能改进技术，而非仅仅取决于材料本身。生产能力预计到2029年将增长两倍以上，但这只有在这些条件具备时才可能成为现实。后续研究应在同一标准下比较不同材料的 LCA，并分析国内分离回收体系中可生物降解塑料的实际处理方式。
